# XPense
XPense is an app built with the mission to help everyone achieve financial independence through learning about and getting into the practice of budgeting, investing, and managing your personal finances. We make it easy and fun for our users by gamifying budgeting and personal finance management.

## Development

This is a React + TypeScript app built with Vite and Tailwind CSS.

```bash
npm install
npm run dev      # start the dev server
npm run build    # type-check and build for production
npm run preview  # preview the production build locally
```
